📌 REPLIT PROMPT — STEP 3: ADMIN SLOT MANAGEMENT
Extend the PGJ Booking System Node.js Express application with Admin Slot Creation, Blocking, and Manual Booking.

🔒 DATABASE & SAFETY RULES
Use the existing MySQL database


Do NOT drop tables


Do NOT modify table structure


Only INSERT or UPDATE records related to slots and bookings


Use MySQL transactions


Enforce no double booking



🧠 BUSINESS RULES (MANDATORY)
Slots are created only by Admin


Parents can only book slots created by Admin


Booking is first-come-first-served


Slot statuses:


AVAILABLE


BOOKED


BLOCKED


Once a slot is BOOKED, it cannot be booked again


Admin may override and book any slot



🛠 ADMIN ROUTES
GET /admin/slots/create/:teacherId
Display slot creation form


Inputs:


Meeting Date


Start Time


End Time


Slot Duration (minutes)


POST /admin/slots/create
Auto-generate slots based on duration


Skip blocked ranges


Prevent overlapping slots


POST /admin/slots/block
Block a slot


Inputs:


Slot ID


Block Reason (Lunch, Snack, Unavailable)


POST /admin/slots/book
Admin manually books a slot


Lock slot row using SELECT ... FOR UPDATE


Update status to BOOKED


Record booking source as ADMIN



🧩 DATA INTEGRITY
Reject booking if slot status ≠ AVAILABLE


Reject slot creation if overlap detected


All booking operations must be transactional

Mobile-first admin forms


Clear success and error feedback
