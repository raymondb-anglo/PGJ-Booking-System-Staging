📌 REPLIT PROMPT — REPORTS & AUDIT LOGS

Implement the Reports & Audit Logs module for the booking system.

This module must provide:

Operational visibility

Exportable reports

Full audit trace for critical actions

⚠️ This is read-heavy and must NOT affect booking performance.

📊 PART 1 — REPORTS DASHBOARD (ADMIN)

Create Admin → Reports with the following sections.

📈 SUMMARY CARDS (TOP)

Show real-time counts:

Total Students

Total Teachers

Total Meeting Dates

Total Time Slots

Total Bookings

Bookings Sent via Email

Bookings with PDF Downloaded

Available Slots Remaining

Cards update dynamically based on filters.

🖥️ PART 5 — AUDIT LOG VIEWER (ADMIN)

Create Admin → Audit Logs page:

Features

Filter by:

Date range

Actor

Action

Entity type

View:

Before / After values

Read-only (no delete/edit)

Pagination required

⚠️ SUPER_ADMIN sees all
⚠️ ADMIN sees logs but cannot export

🔒 ACCESS CONTROL

SUPER_ADMIN:

Full access

Export allowed

ADMIN:

View reports

Limited exports (CSV only)

View audit logs (read-only)

Parents & teachers:

No access

🧪 PERFORMANCE & SAFETY

Use indexed columns for filters

Audit logging must be async-safe

Logging failures must NOT block main action

No sensitive data exposure (mask emails if needed)

🖥️ UI REQUIREMENTS

Mobile-friendly tables

Sticky filters on desktop

Empty states with guidance

Global loader on data fetch

✅ ACCEPTANCE CRITERIA

Accurate real-time reports

Filters work correctly

Exports match filtered data

All critical actions logged

Audit logs immutable

No performance regression
